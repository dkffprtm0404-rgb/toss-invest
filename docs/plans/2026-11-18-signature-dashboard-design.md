# TossInvest 첫 화면 구성 설계안

작성일: 2026-11-18 · 상태: 전략 데스크 안 승인

적용 범위: 기존 기능과 문구를 유지하고 PC와 모바일 배치만 바꾼다. [구현 계획](2026-11-18-strategy-desk-implementation.md)을 따른다.

## 목적

문장으로 투자 전략을 쓰고 과거 데이터로 검증하는 작업이 첫 화면에서 TossInvest의 인상으로 남게 한다. 기존 전략 작성, 백테스트, 계좌와 모의매매 기능을 재배치한다.

## 비교한 구성

| 구성 | 첫 화면의 중심 | 적합한 이용 상황 |
| --- | --- | --- |
| 전략 데스크 (권장) | 왼쪽의 넓은 전략 입력창과 작성부터 실행 결과까지 이어지는 단계 띠. 오른쪽에는 장전 요약. | 새 전략을 쓰거나 기존 전략을 검증하려는 사용자가 바로 시작할 수 있다. |
| 시장 보드 | 상단을 가로지르는 지수·환율 요약. 그 아래에 전략 입력창과 단계 띠. | 시황을 먼저 확인하는 사용자가 읽기 쉽다. 모바일에서는 전략 입력이 뒤로 밀린다. |

[네이버](https://www.naver.com/)의 검색 입력, [삼성닷컴](https://www.samsung.com/sec/)의 대표 제품 영역, [Npay 증권](https://stock.naver.com/)의 시장 현황은 각각 주된 이용 목적을 첫 화면에 배치한다. TossInvest의 대표 행동은 기존 전략 입력이므로 전략 데스크를 권장한다.

## 전략 데스크 배치

- **헤더:** 기존 워드마크와 주황색 슬래시를 유지하고 `투자 전략`·`계좌·모의매매` 탭을 그 높이에 배치한다. 시각과 연결 상태는 보조 정보로 둔다.
- **데스크톱:** 기존의 큰 문구 영역을 전략 입력창에 내준다. 너비 약 2/3의 짙은 작성 영역에 실제 입력창, 조건 해석 버튼, `전략 작성 → 확인·저장 → 저장 전략 → 백테스트 → 실행 결과` 순서를 한 덩어리로 둔다. 나머지 1/3에 장전 AI 시장 요약을 둔다. 단계 띠는 기존 작업 바로가기를 재사용한다.
- **브리핑:** 저장 브리핑에 있는 코스피·코스닥·원/달러를 요약에 사용한다. 관측 기준과 자료 누락 상태를 표시하고, 전체 요약·출처·새로고침·생성은 상세 영역에 유지한다. 새로운 시세 요청이나 실시간 차트는 추가하지 않는다.
- **아래 영역:** 나머지 작업 화면에서 기존 조건 편집, 저장 전략, 백테스트, 실행 결과와 비교를 이어간다. 시안 하단의 두 칸은 기존 저장 전략과 실행 결과의 위치를 가리킨다.
- **모바일:** 탭, 작성 영역, 장전 요약, 후속 작업 순으로 쌓는다. 기존 입력창을 그대로 사용해 두 개의 입력값을 동기화할 필요가 없게 한다.

## 적용 시 확인할 사항

- 새 접속에서 브리핑 로딩·누락이 전략 입력과 탭을 밀어내지 않는다. 기존 브리핑 펼침과 계좌 가림 설정도 유지한다.
- 탭을 전환해도 작성 중인 전략과 실행 결과가 유지된다. 키보드 탐색, 상세 브리핑 토글, 계좌·모의매매 접근도 확인한다.
- 1440px 데스크톱과 390px 모바일에서 입력과 조건 해석 버튼이 첫 화면 안에 들어온다. 320px에서는 겹침이나 문서 전체의 가로 스크롤이 없는지 확인한다.
- 전략 해석·저장·실행 흐름, 계좌 조회·발표용 공백 처리의 기존 브라우저 테스트를 실행한다. 데이터와 API 동작은 변경 범위에 포함하지 않는다.
