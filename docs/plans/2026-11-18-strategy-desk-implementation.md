# 전략 데스크 구현 계획

> **For agentic workers:** Use superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 기존 기능과 문구를 유지하고 승인받은 전략 데스크를 PC와 모바일에 적용한다.

**Architecture:** 기존 탭을 공통 헤더에 올린다. 첫 줄의 작성 칸에 실제 전략 입력 폼을 옮기고, 같은 브리핑 노드를 두 탭에서 사용한다. 상세 편집·저장·백테스트는 기존 작업 영역에서 실행한다.

**Tech Stack:** 기존 HTML, CSS, JavaScript, Node 테스트와 Playwright

**Spec:** [TossInvest 첫 화면 구성 설계안](2026-11-18-signature-dashboard-design.md)

## 적용 범위

- 기존 화면 문구, 버튼·폼 ID, 전략 처리와 계좌 기능, API 및 저장 동작을 유지한다. 새 시세 요청이나 입출력 필드를 추가하지 않는다.
- 첫 화면 브리핑은 저장된 세 시장 지표만 간단히 보여준다. 새 방문은 상세를 접어 두고, 명시적인 펼침·접힘 설정은 기존 키로 복원한다. 자료 누락과 실제 관측 시각을 표시한다.

## 확인할 경우

- 상세 브리핑이 펼쳐져도 PC에서 작성 입력과 나란히 시작하고, 모바일에서는 작성 입력이 먼저 보인다.
- 320px에서 문서 수준의 가로 스크롤이 없다. 카드 안의 기존 표 스크롤은 유지한다.
- 계좌로 이동했다 돌아와도 같은 초안과 브리핑 설정이 남는다.
- 새 입력 칸으로 옮긴 조작도 전략 작업 중에는 잠기며, 브리핑 조작은 별도로 가능하다.
- 저장본 조회 실패, 일부 누락, 휴장 상태에 임의 값이나 실시간 시세가 표시되지 않는다.
