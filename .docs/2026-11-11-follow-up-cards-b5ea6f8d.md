## 등록 절차와 현재 제약

1. 업무 보드 조회 권한이 있는 담당자가 위 두 제목과 같은 범위의 기존 카드를 확인한다.
2. 기존 카드가 있으면 그 제목·상태를 회신하고 문서 내용을 해당 카드에 연결한다.
3. 같은 범위의 카드가 없을 때만 두 제목으로 신규 등록하고 제목·등록 결과를 회신한다.
4. 등록 확인 근거를 받기 전에는 문서 작성이나 도움 요청 접수를 카드 생성 완료로 보고하지 않는다.

- 서버 개발 담당 회신: 업무 보드 조회 도구가 없고 AI Office 화면 접근도 차단됐다. 도움 요청 사슬에서는 카드 생성·재위임이 불가하다는 사무실 도구 응답을 받았으며 신규 등록하지 않았다.
- 이번 턴: 읽기 명령 3건이 자동 승인 검토에서 `rejected by user`로 거절됐고 상세 사유는 제공되지 않았다. 차단된 기존 파일 조회를 다른 수단으로 재시도하지 않았다.
