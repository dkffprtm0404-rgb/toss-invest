# 단타 매매 규칙 (Trading Rules v2.0)

> 본 문서는 자동매매 봇의 "판단 엔진"이 따를 매매 규칙을 정의한다.
> 실제 주문 실행 전 단계이며, 신호 생성 → 백테스트 → 페이퍼 트레이딩 → 소액 실거래 순으로 단계를 밟는다.
>
> v1.0(2026-06-16) 작성 후, 타 LLM 교차검증 피드백을 반영해 v2.0으로 개정했다.
> 주요 변경: SMA→EMA 전환, RSI 기간 단축, 고정 익절→트레일링 스탑, 점수제 도입, 시장 필터 추가.
> 변경 사유는 각 섹션에 "v1→v2 변경 사유"로 남긴다.

---

## 0. 기본 철학

- 단타는 "하루~며칠 내 청산"을 기본으로 한다. 포지션을 오래 들고 가지 않는다.
- 단일 지표로 진입하지 않는다. 점수제(2장)로 신호 강도를 합산해 임계값 이상일 때만 진입한다.
- 수익보다 손실 제한이 먼저다. 손절 규칙이 없는 매수 신호는 무효로 취급한다.
- 종목 자체가 좋아도 시장 전체가 무너지는 날엔 신규 매수를 보류한다 (시장 필터, 4장).
- 모든 판단은 캔들(OHLCV) 데이터 기반으로 계산하며, 사람의 직감이나 뉴스 감성은 1차 판단에 포함하지 않는다.
- 봇은 1단계에서는 "신호 생성"까지만 한다. 실주문은 사람이 최종 승인하거나, 충분히 검증된 후 별도 활성화한다.

## 1. 사용 지표 정의

### 1.1 이동평균선 — EMA로 전환 (v1→v2 변경)
- **v1→v2 변경 사유**: SMA5/SMA20은 반응이 느려 골든크로스 시점에 이미 5~10% 상승한 뒤인 경우가 많다는 피드백을 받았다. 단타에는 최근 가격에 가중치를 더 주는 지수이동평균(EMA)이 적합하다.
- 단기선: EMA5
- 장기선: EMA20
- 골든크로스: EMA5가 EMA20을 아래에서 위로 돌파 → 상승 추세 전환 신호
- 데드크로스: EMA5가 EMA20을 위에서 아래로 돌파 → 하락 추세 전환 신호
- 참고용 보조 조합(추후 실험): EMA9/EMA21

### 1.2 RSI — 기간 단축 (v1→v2 변경)
- **v1→v2 변경 사유**: RSI14는 단타에서 반응이 둔하다는 피드백을 받음. 짧은 기간일수록 변동에 민감하게 반응한다.
- 계산 기간: **RSI7** (기본값. RSI9도 실험 후보로 남겨둔다)
- 과매도: RSI ≤ 30 → 단기 반등 가능성, 매수 후보
- 과매수: RSI ≥ 70 → 단기 하락 가능성, 매도/진입 보류 후보
- 중립 구간(30~70)은 단독으로 신호를 발생시키지 않는다.

### 1.3 거래량 동반 여부
- 직전 5일 평균 거래량(VOL_AVG5) 대비 당일 거래량이 1.5배 이상이면 "거래량 동반"으로 판단한다.
- 거래량 동반 없는 가격 돌파는 신뢰도가 낮은 신호로 간주해 점수를 낮게 준다 (2장 점수표 참고).

### 1.4 가격 돌파 (Breakout)
- 직전 N일(기본 5일) 최고가를 당일 종가(또는 현재가)가 상향 돌파하면 상승 돌파.
- 직전 N일 최저가를 하향 돌파하면 하락 돌파.

### 1.5 변동성 돌파 (래리 윌리엄스 방식)
- 목표가 = 당일 시가 + (직전일 고가 − 직전일 저가) × K
- K는 0.5를 기본값으로 사용한다 (보수적 설정).
- 현재가가 목표가를 상향 돌파하면 매수 후보로 추가 고려한다.
- 1일봉 기준으로만 사용하며 분봉에는 적용하지 않는다.

### 1.6 시장 지수 필터 — 신규 추가 (v2)
- **추가 사유**: 종목 단독 판단만으로는 시장 전체가 폭락하는 날에도 매수 신호가 나올 수 있다는 피드백을 받음.
- 코스피(KOSPI) 또는 코스닥(KOSDAQ) 지수가 자체 EMA20 위에 있을 때만 신규 매수를 허용한다.
- 지수가 EMA20 아래일 경우: 신규 매수 신호를 보류(HOLD)하고, 보유 종목의 매도 판단은 그대로 수행한다.
- 토스증권 Open API에서 지수 시세 제공 여부 확인 필요 (미확인 시 임시로 종목 자체 판단만 사용하고 TODO로 표시).

## 2. 매수 신호 — 점수제 (v1→v2 변경)

- **v1→v2 변경 사유**: "2개 이상 동시 충족"이라는 단순 카운트 방식은 조건 간 신뢰도 차이를 반영하지 못한다는 피드백을 받음. 점수제로 전환해 강한 신호(거래량 돌파)에 더 큰 가중치를 준다.

| 조건 | 점수 |
|---|---|
| A. 골든크로스 (EMA5가 EMA20을 상향 돌파, 최근 1~2봉 이내) | 2 |
| B. RSI(7) 과매도 반등 (30 이하에서 다시 30 상향 돌파) | 1 |
| C. 거래량 동반 직전 5일 최고가 돌파 | 3 |
| D. 변동성 돌파 목표가 도달 | 2 |

**매수 신호 발생 조건: 총점 5점 이상**

**제외 조건 (아래 중 하나라도 해당하면 점수와 무관하게 매수 신호 무효화):**
- RSI ≥ 70 (이미 과매수 구간) — 단, 조건 C가 단독으로 매우 강할 경우는 예외적으로 별도 검토
- 시장 지수가 자체 EMA20 아래인 경우 (1.6 시장 필터)
- 당일 거래량이 직전 5일 평균보다 현저히 낮은 경우 (관심도 저하)

**v1에서 삭제된 제외 조건 (v1→v2 변경):**
- (삭제) "최근 3일간 -10% 이상 급락 시 제외" — 급락 후 거래량 폭증 + 장대양봉이 나오는 바닥 반등 패턴이 단타에서 유효한 기회일 수 있다는 피드백을 받아 삭제함.
- (대체) 급락 직후 진입 시에는 제외하지 않되, 점수표의 거래량 조건(C, 3점)이 충족되지 않으면 자연히 점수 미달로 걸러지도록 한다. 즉 "무조건 차단"에서 "거래량으로 신뢰도 검증"으로 완화.

## 3. 매도(청산) 신호 규칙

### 3.1 손절 (Stop Loss) — 최우선 규칙, 변경 없음
- 매수가 기준 **-2% 도달 시 즉시 매도 신호** (조건 없이 무조건 실행 대상).
- 손절 기준은 절대적이다. 예외를 두지 않는다.

### 3.2 익절 — 트레일링 스탑으로 전환 (v1→v2 변경)
- **v1→v2 변경 사유**: 고정 익절(+3~5%)은 큰 상승(+10% 이상)을 짧게 끊어버려 기대수익을 낮춘다는 피드백을 받음. 트레일링 스탑으로 전환해 추세가 살아있는 동안은 따라가고, 꺾이는 시점에만 청산한다.

| 수익률 구간 | 동작 |
|---|---|
| +3% 도달 | 손절 기준선을 매수가(0%, 본전)로 상향 — 더 이상 손실 안 나게 보호 |
| +5% 도달 | 손절 기준선을 +2%로 상향 |
| +8% 도달 | 손절 기준선을 +5%로 상향 |
| 이후 +3%p 상승마다 | 손절 기준선을 직전 임계값으로 동일하게 +3%p씩 상향 |
| 현재가가 손절 기준선 아래로 하락 | 즉시 매도 (트레일링 스탑 발동) |

- 트레일링 스탑이 한 번도 발동되지 않은 상태(즉 +3% 미도달)에서는 3.1의 -2% 손절만 적용된다.

### 3.3 추세 전환 매도
- 데드크로스(EMA5가 EMA20을 하향 돌파) 발생 시 매도 신호.
- 보유 중 직전 5일 최저가를 하향 돌파(거래량 동반) 시 매도 신호.

### 3.4 시간 기반 청산 (단타 원칙)
- 매수 후 **3거래일 이내** 익절/손절 조건에 도달하지 않으면 보유 사유를 재검토한다.
- 5거래일을 초과해도 신호가 없으면 강제 재평가 대상으로 표시한다 (자동 매도는 아니며, 별도 검토 신호로만 표시).

## 4. 리스크 관리 규칙

- **1회 매수 비중**: 전체 가용 자산의 10% 이내로 제한 (한 종목에 몰빵하지 않음).
- **동시 보유 종목 수**: 분산을 위해 최소 2종목 이상, 과도한 분산 방지를 위해 최대 5종목 이내.
- **연속 손절 제한**: 동일 종목에서 연속 2회 손절이 발생하면, 해당 종목은 최소 3거래일간 매수 후보에서 제외한다.
- **일일 손실 한도**: 하루 누적 손실이 전체 자산의 -3%에 도달하면 그날은 모든 신규 매수 신호를 중단한다 (청산/손절은 계속 수행).
- **시장 필터 연동**: 1.6의 시장 지수 필터가 발동(지수 < EMA20)되면 신규 매수를 보류한다.

---

## 5. 신호 우선순위 및 충돌 처리

1. 손절(3.1) 및 트레일링 스탑(3.2) 신호는 다른 모든 신호보다 우선한다 (즉시 실행).
2. 동일 종목에서 매수 신호와 매도 신호가 동시에 발생하면 매도를 우선한다 (보수적 원칙).
3. 여러 종목에서 매수 신호가 동시에 발생하면, 점수(2장)가 높은 종목 순으로 우선순위를 부여한다.

## 6. 단계별 실행 계획 (검증 절차)

1. **신호 생성 단계 (현재 단계)**: 캔들 데이터 기반으로 매수/매도 신호만 생성하고 기록한다. 실주문 없음.
2. **백테스트 단계**: 최소 2~3년치 과거 캔들 데이터에 위 규칙을 적용해 승률, MDD(최대낙폭), 손익비, 샤프비율을 검증한다.
3. **페이퍼 트레이딩 단계**: 실시간 데이터로 신호를 생성하되 가상으로만 매매를 기록한다 (최소 2주 권장).
4. **소액 실거래 단계**: 최소 금액으로 실제 주문을 실행하며 1~2주 모니터링한다.
5. **점진적 확대**: 소액 단계에서 안정성이 확인된 후에만 금액을 늘린다.

> 본 프로젝트는 현재 1단계(신호 생성)에 있다. 2단계 이후로 넘어가기 전 반드시 사람의 검토와 승인이 필요하다.

## 7. v1 → v2 변경 요약

| 항목 | v1 | v2 | 사유 |
|---|---|---|---|
| 이동평균 | SMA5 / SMA20 | EMA5 / EMA20 | 반응 속도 개선 |
| RSI 기간 | 14 | 7 | 단타에 맞게 민감도 향상 |
| 매수 판정 방식 | 조건 2개 이상 충족 | 점수제 (5점 이상) | 조건별 신뢰도 차등 반영 |
| 익절 | 고정 +3~5% | 트레일링 스탑 | 큰 상승 추세를 짧게 끊지 않도록 |
| 급락 후 진입 | 3일 -10% 시 무조건 제외 | 제외 조건 삭제, 거래량 조건으로 자연 필터링 | 바닥 반등 기회 보존 |
| 시장 필터 | 없음 | 코스피/코스닥 EMA20 필터 추가 | 시장 전체 하락일 신규 매수 차단 |

## 8. 본 문서의 한계 및 주의사항

- 위 규칙은 일반적으로 알려진 보조지표 기반 단타 기법과 외부 교차검증 피드백을 조합한 것으로, 특정 시장 국면(추세장/횡보장)에 따라 성과가 달라질 수 있다.
- 점수표의 가중치(2/1/3/2)와 임계값(5점), 트레일링 스탑 구간(+3/+5/+8%)은 초기 추정값이며, 백테스트 결과에 따라 조정될 수 있다. 변경 시 changelog.md와 본 문서 7장에 기록한다.
- 본 규칙은 투자 자문이 아니며, 실거래 전 충분한 백테스트와 소액 검증이 선행되어야 한다.
- 손절 규칙(3.1)은 어떤 경우에도 예외 없이 지킨다.
